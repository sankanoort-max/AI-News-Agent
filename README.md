

\# AI News Agent



An AI-powered news agent that collects recent news from RSS feeds, cleans and deduplicates articles, summarizes and ranks news using Ollama, and emails the top stories.



\## Features



\- Collects news from multiple RSS feeds

\- Cleans and deduplicates articles

\- Uses Ollama for AI summaries and relevance scoring

\- Selects the top 10 news stories

\- Sends a news digest through email



\## Technologies



\- Python

\- Jupyter Notebook

\- RSS feeds

\- Ollama

\- Pandas

\- Requests

\- Feedparser



\## Prerequisites



\- Python and Jupyter Notebook

\- Ollama installed and running

\- The configured Ollama model

\- Gmail SMTP configuration for email delivery



\## Setup



Install dependencies:



pip install -r requirements.txt



Ensure Ollama is running and the configured model is available before executing the notebook.



\## Security



Never commit Gmail app passwords, API keys, or other credentials to GitHub.
